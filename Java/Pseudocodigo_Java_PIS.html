Java · recepción y presentación

Selecciona el puerto, reconstruye líneas, valida campos y representa el resultado. Se proponen historial en memoria y exportación CSV. No se enviarán órdenes a la placa en esta primera versión.

¿Por qué no calculamos otra vez el nivel en Java?

Porque el ESP32 ya lo envía junto con el estado. Recalcular con otra altura o límites produciría contradicciones entre la pantalla y los LED. Java valida estructura y tipos; comprobar la calibración física sigue siendo otra tarea.

¿Qué diferencia hay entre ERROR, formato inválido y desconexión?

ERROR es un mensaje válido de la placa que informa una medición fallida. Formato inválido es una línea que no cumple el contrato: se descarta y registra. Desconexión es un fallo del transporte. El silencio prolongado deja la conexión incierta y la medición antigua, aunque el puerto parezca abierto.

¿Por qué usamos un lector en segundo plano?

Esperar datos puede tardar. Si la misma tarea atendiera la ventana, los botones dejarían de responder. El lector entrega resultados; el hilo de interfaz actualiza la pantalla. No son dos programas distintos, son tareas de la misma aplicación.

¿Qué pasa si el agua entra en la zona ciega del sensor?

El firmware actual puede informar ERROR y apagar el buzzer. Java debe mostrar “medición no disponible”, nunca “normal”. Esta limitación debe resolverse con la ubicación del sensor y las pruebas; esta guía no la corrige.

¿Qué cambiaría si usamos Wi-Fi?

Cambiarían la conexión y recepción. El formato PIS1, la validación, los registros y la presentación pueden conservarse si mantenemos el contrato. Es la razón para separar responsabilidades.

Guion breve para explicarlo al grupo

“Primero abrimos el puerto a la misma velocidad que el ESP32. Después reunimos los bytes hasta completar una línea. Validamos sus siete campos y, si son correctos, actualizamos la pantalla y el historial. Un temporizador detecta silencio. Al finalizar, liberamos el puerto. Separamos estas tareas para evitar bloqueos y distinguir un nivel alto de una falla de medición”.

Diccionario rápido

Buffer: espacio temporal para reunir fragmentos. Evento: algo que ocurre, como pulsar Conectar. Hilo: tarea de ejecución. CSV: texto organizado en campos y filas. NA: dato no disponible. Sesión: una conexión concreta, desde abrir hasta cerrar. Reloj monotónico: contador para medir intervalos sin depender de cambios de fecha.
