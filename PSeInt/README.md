## Entrega pendiente

Falta incorporar el algoritmo ejecutable `.psc` y comprobarlo en PSeInt. Las guías HTML no son un algoritmo ejecutable ni completan por sí solas ese requisito. El pseudocódigo de la guía corresponde al diseño anterior de comunicación USB; el destino actual del monitoreo es la web por Wi-Fi.

Cada integrante debe subir su aporte con su propia cuenta. No se asignan aportes ni autorías individuales a partir de esta organización.
