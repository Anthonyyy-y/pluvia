    Cómo conectar la placa

    USB. Carga PluviaDos, abre esta página mediante HTTPS o localhost en un navegador con Web Serial y selecciona el puerto a 115200 baudios. El monitor sólo lee el puerto.

    Wi-Fi local. Configura la red en el sketch. La placa imprime su URL en el Monitor Serie. Conecta el equipo a la misma red y abre el sitio desde un servidor HTTP local. Un sitio HTTPS puede bloquear una placa HTTP por contenido mixto. Para conservar HTTPS, usa USB, la nube o un proxy HTTPS de confianza que reenvíe a la IP privada de la placa.

    Estanque. El firmware informa segundos estimados de riego disponible. La reserva se habilita tras confirmar el depósito vacío en la placa. El campo nivelEstanque es null porque el depósito carece de sensor. La estimación independiente se publica como reservaEstimadaS.
