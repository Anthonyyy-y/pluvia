Arquitectura de comunicación

El ESP32 toma las lecturas y envía paquetes autenticados por Wi-Fi a la API HTTPS de Pluvia. El almacenamiento local utiliza SQLite y la publicación en Vercel utiliza PostgreSQL. También puedes consultar la placa desde el navegador por USB o por HTTP en la red local.

Alcance del prototipo

D1 incorpora mecanismos de intervención. D2 supervisa el nivel. Una altura elevada justifica inspeccionar el punto y puede tener distintas causas. La plataforma registra las salidas ordenadas por el controlador.

Calibración y protecciones

La altura útil ocupada requiere calibrar cada recipiente. El estanque carece de sensor. La reserva se estima en segundos de riego y requiere confirmar el vacío tras el arranque. La LCD, las señales y las protecciones funcionan localmente.
